# 第 25 节 — 失效模式：异常值、长上下文、MoE 和小批次

> **谜题：**量化系统首先会在哪里失效？

[← 第 01 章](../README.md) · [项目主页](../../../README_ZH.md) · [执行的笔记本](../../../chapters/01-mixed-precision-int4/25-quantization-failure-modes/lab.ipynb) · [RTX 5090 结果](../../../chapters/01-mixed-precision-int4/25-quantization-failure-modes/artifacts/rtx5090-result.json)

## 为什么这个谜题重要

量化通常在特定条件下失败，而不是平均失败。激活离群值放大了权重误差，移位的域改变了通道的重要性，微小的批次暴露了启动/去量化开销，长上下文扩展了缓存压力，而MoE路由不均匀地集中了工作。失败矩阵在生产前使这些反转变得可见。

## 阅读结果前，先做出预测

1. 预测哪个合成案例会产生最大的W4输出 RMSE。
2. 预测参考 W4 路径在每一批/分布情况下的速度是否更快。
3. 为长上下文缓存和MoE路由设计单独的测试，而线性探针中不包含这些内容。

## 1. 从具体的张量和状态开始

故障模式映射到机制：范围异常、分布偏移、长上下文缓存/注意力、MoE路由不平衡以及小不规则 GEMMs。

### 三个推理锚点

| # | 本课需要牢记的判断 |
|---:|---|
| 1 | 异常值会放大比例并浪费代码在普通值上。 |
| 2 | 长上下文会扩展缓存并可能暴露位置或注意力回归问题。 |
| 3 | MoE路由和小批量创建不规则、对开销敏感的形状。 |

## 2. 推导机制

一个异常值可以扩大group规模；移位输入改变层输出敏感性；批量一和路由专家减少矩阵大小并使启动/去量化开销变得可见。

对于固定权重误差 ΔW，输出误差是 `XΔWᵀ`；直接缩放或平移 X 会改变其大小和方向。这解释了为什么在没有权重字节变化的情况下，一个在普通激活上校准的量化器在遇到异常值或领域偏移时可能会退化。小批量会增加系统故障模式，因为固定启动、解包或缩放开销会摊销到更少的工作量上。

长上下文和MoE需要额外的对象：缓存字节/注意力误差和专家路由负载均衡。它们属于矩阵，但不能从一个密集线性层推断出来。

## 3. 把理论转化为实验**实验：**施加应力 INT4 线性参考，使用普通输入、激活离群值、窄批次以及偏移分布。CUDA.

| 实验角色 | 固定定义 |
|---|---|
| 基准 | BF16 四种受控输入模式下的矩阵乘法 |
| 候选方案 | 相同的乘法运算使用组-128 INT4-去量化权重 |
| 保持不变 | 权重矩阵和量化器；仅批次/分布模式变化 |
| 测量 | 输出 RMSE/cosine 最大误差和中位数/第90百分位时间每种模式 |
| 证据标签 | `pytorch-gpu` |

实验室保持重量固定，并对普通、异常、移位和小批量输入施加应力，保留每种条件，而不是将它们平均在一起。

### 代码导读

该笔记本对一个权重矩阵进行一次量化，然后评估普通、批次-1、激活离群值和移位域输入。每行都包含基准/候选的数值误差和时间。这种配对设计防止了质量失败被一个小的运行速度结果所掩盖。

候选者是一个去量化的 PyTorch 参考张量，而不是一个压缩的生产W4kernel。因此，时间差异表明了复合路径的制度敏感性，而不是 INT4 硬件速度声明。

## 4. 解读仓库内的 RTX 5090 实测结果

**录制环境：**NVIDIA GeForce RTX 5090 计算能力12.0; PyTorch 2.12.0; CUDA 运行时13.0.

| 实测字段 | 已提交值 |
|---|---:|
| 普通 RMSE | 3.729115 |
| 小批量 RMSE | 3.694930 |
| 激活离群值 RMSE | 14.075421 |
| 移域 RMSE | 13.752637 |
| 最大位移最大误差 | 67.176849 |

### 这些数字说明了什么

普通和批次-1 RMSE 关于 3.73 和 3.69。激活离群值将 RMSE 提升至 14.0754，并将最大误差提升至 59.1648；移位域产生了 RMSE 13.7526 和最大误差 67.1768。时间变化保持微小且行间变化不一。

对所有四种情况的综合可能会掩盖大约3.7x在移位状态下的误差跳跃。正确的回应是针对校准、后备或拒绝规则——而不是一个全球声明，即W4是可接受的。

### 这个结论可能如何失效

一个应力张量不能代表生产尾频率，合成时间与去量化权重不是原生后端结果。列出长上下文或MoE的矩阵，而不实际构建缓存或路由证据，也会误导；未执行的轴必须标记为未来门。
