# Lesson 22 — 包装 INT4 推理交付物

> **谜题：**什么文件可以让一个量化模型在一台机器上不仅可加载，而且可复现？

[← 第 01 章](../README.md) · [项目主页](../../../README_ZH.md) · [执行的笔记本](../../../chapters/01-mixed-precision-int4/22-int4-inference-package/lab.ipynb) · [RTX 5090 结果](../../../chapters/01-mixed-precision-int4/22-int4-inference-package/artifacts/rtx5090-result.json)

## 为什么这个谜题重要

量化模型只有在字节和解释一起传输时才能部署。没有缩放因子的压缩权重毫无意义；正确的权重与错误的分词器或基础修订版本一起使用是不安全的；没有校验和的文件无法与部分副本区分开来。因此，打包是推理正确性的一部分，而不是行政清理。

## 阅读结果前，先做出预测

1. 列出加载、验证和回滚量化数据集所需的最小字段。
2. 预测笔记本的重量和尺度张量的压缩负载大小。
3. 解释SHA-256摘要证明了什么，并且它无法检测什么语义错误。

## 1. 从具体的张量和状态开始

可部署的包绑定张量碎片、缩放/零点、形状和打包方案，基础/分词器修订版本、运行时要求、校验和、烟雾向量和回滚标识。

### 三个推理锚点

| # | 本课需要牢记的判断 |
|---:|---|
| 1 | 交付物绑定基版本、量化食谱、分词器、tensor shape、缩放、打包和运行时要求。 |
| 2 | 校验和检测损坏但不验证语义。 |
| 3 | 一个烟雾测试和回滚指针应与该制品相邻。 |

## 2. 推导机制

一个加密散列验证字节，而一个模式验证意义。两者都需要：相同的形状但错误的尺度轴可以是语义上不正确的，但散列一致的。

一个包合同绑定版本、基础修订、量化格式、组大小/轴、tensor shape、缩放dtype、运行时/后端要求、校验和以及回滚目标。校验和确定字节身份；模式确定这些字节应该如何解码。两者都需要。

生产包还包括分词器/配置文件、特殊标记策略、架构代码修订、许可证、模型卡以及质量和性能报告。在实验室中保持一个最小的清单，可以在不发布检查点数据的情况下测试不变量。

## 3. 把理论转化为实验**实验：**创建内存中的合成数据 INT4 分片 CUDA, 仅序列化一个微小的临时负载，验证其校验和和元数据字段，然后删除临时文件。

| 实验角色 | 固定定义 |
|---|---|
| 基准 | 无版本的内存引用权重，没有交接合同 |
| 候选方案 | 临时压缩的 INT4 负载加上验证过的清单和校验和 |
| 保持不变 | 固定tensor shape，分组大小，序列化器，必需字段集，回滚ID |
| 测量 | payload bytes, SHA-256, required-field completeness, cleanup status |
| 证据标签 | `pytorch-gpu` |

实验室创建一个微小的临时压缩载荷，对其进行哈希处理并验证其元数据，然后删除它，以确保没有任何模型检查点进入仓库。

### 代码导读

该笔记本将一个256×512矩阵量化，将代码和缩放序列化到临时文件中，计算SHA-256，记录大小和解释字段，验证所需的密钥，并在检查后让临时负载消失。只有小的元数据证据仍然公开。

该练习证明了包装逻辑，而不涉及权重的提交。它不声称与SafeTensors、Hugging Face量化配置或命名生产运行时兼容。

## 4. 解读仓库内的 RTX 5090 实测结果

**录制环境：**NVIDIA GeForce RTX 5090 计算能力12.0; PyTorch 2.12.0; CUDA 运行时13.0.

| 实测字段 | 已提交值 |
|---|---:|
| Manifest complete | 是的 |
| 载荷字节 | 139,264 字节 |
| 格式 | 参考-INT4 |
| 组大小 | 64 |
| SHA-256 | `bd46d808…6714de` |
| 临时负载已移除 | 是的 |

### 这些数字说明了什么

生成的参考负载为 139,264 字节，并收到摘要 `bd46d8…714de`。每个必需的元表字段都存在，包括基版本、格式、组大小、形状、运行时和 BF16 滚回目标。验证后删除了临时负载。

这是一个可复现性和安全性结果：另一个过程可以验证身份和解释元数据。这不是模型导出、引擎加载或分发许可的决定。

打开[`artifacts/rtx5090-result.json`](../../../chapters/01-mixed-precision-int4/22-int4-inference-package/artifacts/rtx5090-result.json)，当需要每个重复样本或教程表中未选中的字段时。

## 5. 解答谜题并做出决策

> 将版本化的合约连同哈希值、模式、兼容性、烟雾测试和回滚功能一起发送，而不是一个松散的重量文件。

### 验收与回滚门槛

测试新鲜环境加载、哈希验证、模式验证、确定性烟雾输出、内存预算、原生操作符和回滚文件，然后在发布前进行。

### 这个结论可能如何失效

如果生产者和消费者共享相同的错误模式，摘要无法检测到错误的缩放轴。可变模型标签和缺失的分词器修订也会破坏可重复性。永远不要将秘密、本地路径、专有权重或未经授权的数据集放在公共包中，以使教程看起来完整。
