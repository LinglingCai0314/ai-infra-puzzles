# Lesson 21 — 量化视觉和多模态模型

> **谜题：**为什么文本校准集可能遗漏视觉语言模型中的重要故障模式？

[← 第 01 章](../README.md) · [项目主页](../../../README_ZH.md) · [执行的笔记本](../../../chapters/01-mixed-precision-int4/21-multimodal-quantization/lab.ipynb) · [RTX 5090 结果](../../../chapters/01-mixed-precision-int4/21-multimodal-quantization/artifacts/rtx5090-result.json)

## 为什么这个谜题重要

多模态模型没有一个激活分布。块投影看到像素和局部对比度，视觉编码器看到图像标记，连接器映射模态，语言解码器看到文本条件状态。仅校准文本可能会使视觉路径留下未观察到的范围和脆弱的低比特行为。

## 阅读结果前，先做出预测

1. 预测高对比度图像块如何影响一个量化块投影的输出误差。
2. 识别用于视觉语言模型所需的校准层，而不是仅用于文本的LLM。
3. 解释为什么补丁投影结果不能建立完整的VLM质量。

## 1. 从具体的张量和状态开始

一个视觉-语言系统包含一个视觉编码器、补丁/token嵌入、投影器、跨或自我注意力、语言模型和KV缓存。每个组件看到不同的激活分布。

### 三个推理锚点

| # | 本课需要牢记的判断 |
|---:|---|
| 1 | 视觉编码器能够看到块分布、图像对比度和位置结构，这与文本MLP激活不同。 |
| 2 | 一个跨模态管道包含编码器、投影器、语言模型和注意力/缓存对象。 |
| 3 | 覆盖和回退决策可能因组件而异。 |

## 2. 推导机制

Patch projection 将局部像素统计映射到标记中；对比度和模态变化可能会导致文本校准中缺失的通道范围。量化误差随后可能通过归一化和注意力传播。

ViT 的 patch projection 是一个卷积，其核大小和步长等于 patch 大小。对于 16×16 的 RGB patch，每个输出 token 结合了 768 个输入值。权重量化误差通过图像分布进行过滤：高对比度或稀疏极端像素可以放大某些列，而普通的高斯校准方法不会强调这些列。

在更下游的地方，交叉注意力和模态连接器引入了自己的异常值和质量目标。因此，一个稳健的计划会分别对每个组件和每个模态切片进行校准和评估，然后将它们重新组合到端到端的字幕、VQA、OCR或定位任务中。

## 3. 把理论转化为实验

**实验：**量化 CUDA 调整投影权重并比较普通和高对比度合成图像的重建误差。

| 实验角色 | 固定定义 |
|---|---|
| 基准 | 浮点 64 通道，16×16 帖投影 |
| 候选方案 | group-192 INT4-dequantized projection weights |
| 保持不变 | 相同的权重，图像形状，投影步长，正常/高对比度配对输入 |
| 测量 | 投影输出 RMSE/MAE/cosine/max 错误值，每个图像分布的最大值 |
| 证据标签 | `pytorch-gpu` |

该笔记本隔离了一个局部投影，并比较了正常与高对比度图像分布，谨慎地避免了全VLM声明。

### 代码导读

该笔记本将第一个视觉操作隔离，使张量轴保持可读：权重形状为`[64,3,16,16]`，然后扁平化为组进行量化，最后返回到卷积布局。它在普通随机图像和具有周期性对比度峰值的图像上评估相同的候选方案。

该组件测试回答输入分布是否改变局部误差。它故意排除了变压器块、语言解码器、预处理和任务指标，因此其结论在模型质量完全评估之前停止。

## 4. 解读仓库内的 RTX 5090 实测结果

**录制环境：**NVIDIA GeForce RTX 5090 计算能力12.0; PyTorch 2.12.0; CUDA 运行时13.0.

| 实测字段 | 已提交值 |
|---|---:|
| 补丁权重形状 | 64 × 3 × 16 × 16 |
| 正常图像 RMSE | 0.040851 |
| 高对比度 RMSE | 0.063011 |
| 正常最大误差 | 0.202358 |
| 高对比度最大误差 | 0.358466 |

### 这些数字说明了什么

对于正常图像，投影 RMSE 是0.040851，使用余弦0.997531。高对比度块将 RMSE 增加到0.063011，并将最大绝对误差从0.202358增加到0.358466，而余弦保持不变0.997666。

对比偏移下的绝对误差较高，这解释了即使余弦看起来稳定，一个校准分布仍然不足以满足需求。这种变化是否会影响VLM的答案取决于下游的归一化和注意力机制，而本实验室并未对此进行建模。

打开[`artifacts/rtx5090-result.json`](../../../chapters/01-mixed-precision-int4/21-multimodal-quantization/artifacts/rtx5090-result.json)，当需要每个重复样本或教程表中未选中的字段时。

## 5. 解答谜题并做出决策

> 对每个模态和桥梁组件进行校准和回归，而不是在全球范围内应用仅基于文本的决策。

### 验收与回滚门槛

按模态、分辨率、提示长度、OCR/图表案例和组件进行分层校准/评估；测量组件误差加上最终任务的多模态质量。

### 这个结论可能如何失效

仅文本的校准集从未练习过补丁投影。平均图像嵌入也可能隐藏OCR、图表、暗图像或饱和区域。另一个错误是使用图像重建度量来衡量一个部署目标是答案正确性或定位的模型。
